# Shopping Cost Calculator

A simple command-line Java program that calculates the total cost of a purchase.

The program asks for an item, its price, and a quantity, then prints what you bought and the total.

## Requirements

- Java JDK 11 or newer
- IntelliJ IDEA (optional)

## How to Run

1. Clone the repository:
   ```
   git clone https://github.com/<your-username>/<repo-name>.git
   ```
2. Open the project in IntelliJ IDEA.
3. Run `Main.java`.
4. Answer the prompts and press Enter after each one.

## Example

```
What would you like to buy? apple
What is the price of for each?: 1.25
How many would you like?: 4

You have bought 4 apple/s
Your total is $5.0
```

## Concepts Used

- `Scanner` for user input
- Variables and data types (`String`, `double`, `int`, `char`)
- Basic arithmetic and string concatenation
